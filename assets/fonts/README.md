# Fonts

| File | What |
|------|------|
| `GensokyoSans-Regular.ttf` | **Gensokyo Sans**, version 0.6: the proportional face for the interface and for reading. Printable ASCII, all of Latin-1 Supplement and Latin Extended-A (the languages of western and central Europe), the currency, fraction and mathematical signs, the typographic spaces, dashes, quotes and daggers, arrows, the geometric marks and the check mark the desktop uses, superscripts and subscripts, the Romanian Ș ș Ț ț, and the Slavic Cyrillic (U+0400 to U+045F with Ґ ґ) and modern Greek with its tonos and dialytika: 591 code points, 552 glyphs (210 of them accented letters made as composites). Metrics follow `the font specification` (1000 units per em, ascent 940, descent 260, x-height 537, cap height 700; the space is 264 units, the owner's decision of 2026-11-03, the specification first said 240). Has a `kern` table (3003 pairs: the 98 of the plain letters, which the accented ones and the letters that share a glyph with them inherit; see `source/GensokyoSansUI/README.md`). The 107 glyphs of 0.5 are unchanged. |
| `GensokyoSans-Bold.ttf` | **Gensokyo Sans Bold**, version 0.6: a real weight, made from the Regular with its spacing and kerning measured again (stems 154 units against 96, horizontals 130 against 82; the same heights, x-height 537, capitals 700, ascender 740, descender -210, the same code points, 550 glyphs, its own 3003 kern pairs). The toolkit's `kc_text_bold` and the browser's `font-weight: bold` use it. |
| `GensokyoMono-Regular.ttf` | **Gensokyo Mono**, version 0.6: the fixed-width face. One advance of 615 units for every character (two cells for the em spaces), which is 8.0 px at the toolkit's 13 px, the 8 px cell of the 8x16 bitmap font (`the font specification` first said 500, which is 6.5 px at 13 px). The letters of the Regular, centred in the cell and condensed where they would not fit, with `i ı j ȷ l r f I J` redrawn with serifs and the zero dotted, so that `0 O 1 l I |` are six different pictures; the same code points as the Sans (all of Latin-1 and Latin Extended-A but the three that are two letters: IJ, ij, n with an apostrophe; Cyrillic and Greek, the wide letters condensed to the cell), the signs, and **box drawing and block elements in full** (U+2500 to U+259F), which fill the cell exactly (615 wide, from 230 below the baseline to 1000 above it: the 16 pixel row of the toolkit), so that frames join. 748 code points, 709 glyphs, no kerning, `post.isFixedPitch` and the monospaced Panose set, no ligatures yet. The browser's `monospace` (and Courier New, Consolas, ui-monospace) use it. |
| `GensokyoDanmaku-Regular.ttf` | spell-card overlays (dotted, slanted) |
| `GensokyoGap-Regular.ttf` | boundary errors and glitch effects |
| `GensokyoOfuda-Regular.ttf` | shrine notices (brush) |
| `GensokyoFrost-Regular.ttf` | ice warnings and Cirno screens |
| `GensokyoKappa-Regular.ttf` | instrument displays (segmented) |
| `GensokyoMischief-Regular.ttf` | comic alerts and exclamations |
| `GensokyoSeals-Regular.ttf` | barrier notices, stamps and badges |

The seven display faces map lowercase input to capitals and cover printable ASCII only; they are for short labels and headlines, not for text. None of the display faces has a bold weight, accented letters, a fixed-width cut or kana; Gensokyo Sans has no italic (the browser slants the Regular) and no kana, and its Greek and Cyrillic are the modern Slavic and Greek letters only; Gensokyo Mono has no bold and no ligatures.

Original work, drawn for this project from `source/` (Python generators using fontTools: `python src/build.py` then `python tools/check.py` in each of the three folders, as `source/HANDOFF.md` and `source/README.md` explain). **License: SIL Open Font License 1.1, no Reserved Font Name** (`OFL.txt`, also `LICENSE` in each folder of `source/`; copyright 2026 STONERJ25; decided 2026-11-08; every font's name table carries the notice, a sentence about the license and its address, which `tests/host/test_font_license.py` checks); the OS's built-in 8x16 bitmap font is a different thing (`shared/font8x16.c`, from DejaVu Sans Mono: `LICENSE_DEJAVU`).
`SHA256SUMS` holds the checksums of the delivered files (`sha256sum -c SHA256SUMS` in this folder).

In the OS image the files are installed as `/ScarletDevilMansion/share/fonts/*.ttf` (`tools/build.py`). Since 2026-11-03 the desktop's text is set in Gensokyo Sans (13 px) through the toolkit: `user/lib/kappa`, switched by `KAPPA_TTF` (default 1), with the 8x16 bitmap font for the terminal, the text areas, the pixel-art programs and the characters Gensokyo Sans lacks (the terminal and the Notebook did not move to Gensokyo Mono: at 13 px, unhinted, it is softer than the crisp one pixel strokes of the bitmap font; `docs/TTF.md`, "State of the work on `agent/fonts-latin`", has the measurements) (see `docs/TTF.md`, "The desktop in Gensokyo Sans"). The seven display faces are not used by the desktop yet. `tests/host/test_ttf.py` (`OwnerFonts`) checks the checksums above and reads every file; rebuilding a font means installing it and updating `SHA256SUMS` (`python tools/install.py` in `source/GensokyoSansUI` does both). The Bold is read by a program the first time it draws bold text (35 KB, in the initrd with the Regular: the two Gensokyo Sans files added 27 KB and 35 KB to the image, the Mono 31 KB, which no program reads yet but the browser).
