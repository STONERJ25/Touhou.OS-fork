# The cascade and computed values: "=== name [options]" (options: w=WIDTH h=HEIGHT dark print), a document, then lines
# "selector | properties => values" with one value per property, separated by " ; ", for each matching element in tree
# order (elements separated by " || "). Values are the engine's serialization of computed values: rgb(...) colours,
# lengths in px, keywords.

=== specificity and order
<style>p { color: red } .c { color: green } #t { color: blue } p.c { color: purple }</style><p id=t class=c>x</p><p class=c>y</p><p>z</p>
p | color => rgb(0, 0, 255) || rgb(128, 0, 128) || rgb(255, 0, 0)

=== later rules win at equal specificity
<style>.a { color: red } .b { color: green }</style><p class="b a">x</p>
p | color => rgb(0, 128, 0)

=== important and the style attribute
<style>#t { color: red !important } p { color: blue !important } #u { color: green }</style><p id=t style="color: yellow">x</p><p id=u style="color: yellow">y</p><p id=v style="color: yellow !important">z</p>
p | color => rgb(255, 0, 0) || rgb(0, 0, 255) || rgb(255, 255, 0)
